# pause_index chain — 残存微妙差分

## 確定済み
- FUN_0044b2a0: index∈{1,2,3,4} → {1000,3000,5000,20000}、enable +0xb8=0/bc=c0=c4=1
- index計算は選択エントリの classcode byte (+0x14) の桁のmin-chain

## 残存差分（静的限界）
オリジナルのindex計算は b850/b320 で辿る「選択エントリのリンクリスト」上の
複数エントリの class 桁を組み合わせる。我々のポートは request.class/10 で近似。
単語スコープでは一致するが、リンク先のエントリクラスが要求クラスと異なるケースで
indexがズレる可能性がある。

例: 「가」1語 → 我々 idx=4 → pause=20000。本来のリンク辿りでは別値の可能性。

## 影響範囲
文末・無音挿入長のみ。ユニット選択そのもの（wlen/pitch）は影響を受けない。

## 次の一手
b850/b320 のリンクリスト構造を完全デコードすれば静的で正確に再現可能。
あるいは wine バッチキャプチャで pause 値を実測して検証。
